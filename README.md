# Poker Night

The scorekeeper for your home game. Track buy-ins and rebuys with one tap, count
everyone down at the end, and get the fewest possible payments to settle up.

```
npm install
npm run dev
```

Runs entirely on your phone — no accounts, no server, no network. Add it to your
home screen and it behaves like an app.

See `DESIGN-SPEC.md` for the product and design intent.
